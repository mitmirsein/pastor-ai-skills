# 📚 비서의 서재 (Data Shelf) — 정본 데이터 슬롯

> v2.8 (P0-1). 이 디렉터리는 **슬롯**입니다 — 비어 있어도 툴킷은 동작하지만, 채우면 스킬들이 자동으로 인지하여 검증 품질이 올라갑니다.
> 🚨 **저작권 주의**: 개역개정 등 저작권이 있는 본문은 이 공개 저장소에 커밋하지 마십시오. 슬롯은 *사용자 로컬 주입* 전용이며, `data/scripture/`·`data/terms/`의 내용물은 `.gitignore`로 제외됩니다.

## 동작 원칙 — 본문 팩 우선 (Passage-Pack First)

성경 본문을 다루는 모든 스킬은 분석 전에 본문 전문을 확보합니다 (`core/_hooks.md` §6):

1. `data/scripture/`에 해당 책 파일이 있으면 거기서 본문을 가져옵니다.
2. 없으면 사용자에게 **본문 전문 붙여넣기를 요청**합니다.
3. **기억으로부터의 성경 인용은 금지**됩니다 — 확보된 본문 팩이 유일한 인용 원천이며, 대조 불가 인용은 "(검증 불가)"로 표기합니다.

## 슬롯 1: `data/scripture/` — 성경 본문

사용자가 보유한(사용권이 있는) 성경 본문 파일을 넣습니다.

- **권장 포맷**: 책별 텍스트 파일, 절 단위 줄바꿈.
  - 파일명: `{책이름}.txt` (예: `마태복음.txt`, `시편.txt`) — 한글 책명 그대로.
  - 줄 형식: `장:절 본문` (예: `5:3 심령이 가난한 자는 복이 있나니 천국이 그들의 것임이요`)
- 다른 포맷(JSON 등)도 무방합니다 — 에이전트가 책/장/절을 식별할 수 있으면 됩니다.
- 여러 역본을 쓰려면 하위 폴더로 구분: `data/scripture/KRV/`, `data/scripture/NKRV/` 등. 기본 역본은 `core/foundation.md`의 `preferred_bible`을 따릅니다.

### 슬롯 1-b: `data/scripture/source/` — 원어 정본 (선택, v2.12)

원어 분석(파싱·Aspect·강조 표지)의 **대조 기준**입니다. 이 슬롯이 있으면 `sermon-research`의 원어 분석과 `sermon_audit` L1이 실제 텍스트 대조로 격상됩니다.

- 저작권상 자유로운 정본을 직접 받아 넣으십시오:
  - **신약**: SBLGNT (자유 라이선스)
  - **구약**: WLC (Westminster Leningrad Codex — public domain)
  - **칠십인역**: Rahlfs 구판 등 (라이선스 확인 후)
- 포맷 자유 — 책/장/절 식별만 가능하면 됩니다.
- **이 슬롯이 비어 있으면**: 스킬은 원어 형태소 파싱 표를 **생략**하고 의미 범위 논의로 강등합니다. 사전 없는 파싱 단정은 금지 — "요구하되 검증 못 하는" 상태를 만들지 않기 위한 규약입니다.

## 슬롯 2: `data/terms/` — 신학 용어 대조표

신학 용어의 표준 표기를 담은 CSV/TSV를 넣으면, `harness/sermon_audit`(L2)와 발행 스킬들이 용어 표기를 대조합니다.

- **권장 포맷**: CSV, 최소 열 = `용어(ko), 원어/영문, 비고`.
- 없으면 용어 대조는 건너뜁니다(슬롯은 항상 선택).

## 슬롯 3: `data/commentary/` — 서재 팩 (2차 문헌) *(v2.14)*

사용자가 사용권을 가진 주석·신학 저작·교차참조 자료를 넣습니다. 성경 본문(슬롯 1)이 "본문 팩 우선" 원칙의 1차 자료라면, 이 슬롯은 그 위에서 인용되는 **2차 문헌의 검증 기준**입니다 — 있으면 `sermon-research`(Phase 3 신학 족보·해석사)·`biblical-dilemma-solver`·`qt-companion`(브리핑 해석 층)이 **파일 출처를 표기하며 인용**하고, 없으면 현행대로 LLM 지식 + 학파 명시로 정직하게 폴백합니다.

- **포맷 자유(단, 텍스트여야)** — 책/저자/장절을 식별할 수 있는 **마크다운·텍스트** 파일이면 됩니다. 파일별로 나누거나 한 폴더에 모아도 무방합니다.
- **📄 PDF 자료 준비**: 주석·저작이 **PDF**면 서재 팩에 넣기 전에 **마크다운으로 변환**하십시오(스킬은 텍스트를 읽습니다). 이 저장소의 `tools/pdf-extractor/`(선택적 개발자 도구 — Python 실행 환경 필요, `tools/pdf-extractor/VENDOR.md`)가 **텍스트 레이어/OCR된 PDF**를 md로 변환해 줍니다. 스캔 이미지 PDF는 외부 OCR로 텍스트를 입힌 뒤 변환하십시오. 기술적으로 어려우면 md 변환만 도움을 받아 결과물을 넣으셔도 되고, Claude Code 등 일부 환경은 PDF를 직접 읽기도 합니다.
- **최소 메타 의무 (파일 머리에 기재):** `저자` · `전통/학파`(예: 개혁주의·루터교·역사비평) · `서지`(제목·출판연도·쪽). 이 메타가 있어야 `sermon_audit` L2(신학 족보)의 "일부 학자들" 모호성 대조가 실검증이 됩니다 — 메타 없는 파일은 인용은 되나 학파 귀속은 "출처 파일에 전통 미표기"로 강등됩니다.
- **인용 규약**: 서재 팩을 인용할 때는 반드시 출처(파일명 + 저자/쪽)를 함께 표기합니다. **기억으로부터의 인용과 서재 팩 인용을 섞지 않습니다** — 서재 팩에 없는 견해는 "(서재 팩 밖 — 일반 지식)"으로 구분합니다.
- 🚨 **발행물 게재 주의**: 내부 연구용 인용과 발행물(칼럼·블로그·주보) 게재 인용은 저작권상 지위가 다릅니다. 발행 스킬이 서재 팩을 인용하면 **인용 길이를 최소화하고 출전을 명시**하며, 원문 장문 전재는 피합니다.
- **저작권 주의**: 슬롯 1·2와 동일하게 `data/commentary/`의 내용물은 `.gitignore`로 제외됩니다(사용자 로컬 주입 전용, 공개 저장소 커밋 금지).

## 스킬 작성자를 위한 규약

- 슬롯 조회는 **존재하면 사용, 없으면 정직한 폴백** — 데이터가 없다고 추측으로 채우지 않습니다.
- 슬롯 데이터를 인용할 때는 출처(파일명)를 함께 표기합니다.
