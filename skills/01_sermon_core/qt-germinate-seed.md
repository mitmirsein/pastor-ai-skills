# 🌰 큐티-발아-합성 (Germinate Seed)

발아 스캔이 "익었다"고 가리킨 자리의 큐티들을, **시간순으로 원문 그대로 모아** 하나의 설교 씨앗으로 엮는다. 이 스킬은 새 신학을 짓지 않는다 — 목회자가 여러 날에 걸쳐 이미 묵상한 것을 **한자리에 모아 보이게** 할 뿐이다. 그 씨앗이 `sermon-brainstorming`의 출발점이 된다.

## ⚙️ 시스템 프롬프트 (System Instructions & Constraints)

### 🚫 절대 금지 사항 (Hard Constraints)
- **요약·재작성 금지:** 각 큐티의 초기 묵상·대화 프로토콜·심화 묵상을 **원문 그대로** 옮긴다. 매끄럽게 다듬거나 압축하지 않는다(묵상 씨앗 불가침).
- **합성 화이트리스트 (v2.14):** 씨앗에 옮기는 것은 **목회자 발원 텍스트만** — `## 초기 묵상` · `## 대화 프로토콜` · `## 심화 묵상`, 그리고 **긴장 축(qt-germinate-scan 축 3)에서 발아한 씨앗이면 `## 남은 긴장`까지** 포함한다(긴장 발아인데 정작 긴장 원문이 씨앗에서 탈락하는 모순 방지). `## 브리핑 (AI 참고자료)`는 **에이전트 산출물이므로 절대 옮기지 않는다.**
- **원본 불변:** 큐티 원본 파일을 수정·이동·삭제하지 않는다. 씨앗은 항상 **새 파일**로만 만든다.
- **합성 = 이어붙이기:** 여러 큐티를 관통하는 새 결론을 만들어 끼워 넣지 않는다. 반복된 초점을 *색인*으로 정리하는 것까지만 허용하며, 그것은 목회자의 표현을 인용하는 수준이다.

### 🔄 합성 프로세스
1. **대상 확정:** 발아 스캔 후보 번호(예: "1번 아모스 1장"), 목회자가 지목한 본문/주제, 또는 **본문 정박 수확 결과**(`qt-germinate-scan` 모드 2, v2.15)를 받는다. 모호하면 짧게 한 번 확인한다.
2. **큐티 수집(시간순):** `outputs/devotionals/*/`의 목회자 큐티(`qt_kind: dialogue`) + (설정 시) `qt_source_path`의 폴더(들)(콤마 구분 다중 경로 모두)의 노트에서 해당 본문/주제의 큐티를 모아 `captured_at`(YAML `date` 또는 파일 시각) 오름차순으로 정렬한다. 발아 스캔이 세지 않은 것을 새로 지어 넣지 않는다.
3. **씨앗 메모 작성:** 아래 포맷으로 새 파일을 만든다.
4. **접합 안내:** `sermon-brainstorming`에 그대로 붙일 씨앗 블록을 제공한다.

### 📄 씨앗 메모 포맷

```markdown
# 🌰 큐티 씨앗 — {본문 또는 주제}
> 아래는 목회자의 큐티 원문을 시간순으로 그대로 모은 것입니다.
> 요약·가공 없이 원문이며, 원본 큐티 노트는 수정되지 않았습니다.

## 반복된 초점 (스캔이 관찰한 것, 목회자의 표현 인용)
- "{큐티에서 반복된 문구/주제 1}"
- "{반복 2}"

---

## {날짜1} — [[원본 큐티 링크1]]
{그 날 큐티의 초기 묵상 + 대화 프로토콜 + 심화 묵상 — 원문 그대로. 긴장 태생 씨앗이면 남은 긴장도 포함. 브리핑 섹션은 제외}

---

## {날짜2} — [[원본 큐티 링크2]]
{원문 그대로}

---
(시간순으로 이어짐)
```

`## 반복된 초점`은 새 해석이 아니라 큐티에 실제로 등장한 표현의 색인이다. 없으면 생략한다.

### 🎯 정박 수확 태생 씨앗 (v2.15)

`qt-germinate-scan` 모드 2(본문 정박 수확)의 결과에서 온 씨앗은 다음을 따른다:
- **설교 본문의 passage_id에 정박한다** — 저장 폴더·manifest 모두. 다른 본문의 큐티를 포함할 수 있으며, 그 경우 각 큐티 블록 헤더에 원 본문을 병기한다: `## {날짜} — {원 본문} — [[원본 큐티 링크]]`.
- 긴장 공명(수확 H4) 유래 큐티는 `## 남은 긴장`을 포함한다 — 긴장 태생 화이트리스트 규칙(위 합성 화이트리스트) 준용.
- manifest 라인에 `(정박 수확: {설교 본문})`을 병기한다.
- 요약·재작성 금지·원본 불변 등 기존 제약은 전부 동일하다. 수확이 세지 않은 큐티를 새로 지어 넣지 않는다.
