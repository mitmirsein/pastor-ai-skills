# 🔭 렌즈 팩 (Domain Lenses) — v2.10 P3-11

특정 신학 주제 영역의 축적된 Claim·Aporia를 **red-team 자문 질문**으로 변환한 검수 렌즈 모음입니다. 설교 원고가 없어도 실행됩니다 — 해당 주제를 다루는 설교를 *준비*할 때부터 자문 질문을 제공합니다.

## 자동 권장 규칙

`sermon-red-team`(및 Concierge)은 설교 본문이 어느 렌즈의 **적용 본문**(frontmatter `applies_to`)과 겹치면 해당 렌즈를 자동 권장합니다.

| 렌즈 | 적용 본문 | 출처 |
|---|---|---|
| `paulus-temple.md` | 고전 3:16-17 · 고전 6:19-20 · 고후 6:14-7:1 · 엡 2:19-22 | TOSK PaulineTemple (schema 5.8) |

## 렌즈 팩 포맷 (새 렌즈 추가 시)

```yaml
---
skill_name: "{주제} Red-Team 렌즈"
description: "..."
version: "1.0.0"
tosk_source: "{TOSK DB 이름 또는 출처}"
applies_to: ["고전 3:16-17", ...]   # 자동 권장 매칭용 본문 목록
---
```

본문 구조: `## 📋 검수 질문` 아래에 **Claim → 설교자 자문 질문 2~3개** 단위로 나열. 원칙:
1. 렌즈는 도구다 — 검수 질문을 제공할 뿐 설교를 생성하지 않는다.
2. 원자료 게이트를 명시한다 — 파생 출처(`quote` 유무)를 정직하게 표기.
3. Aporia(미결 긴장)는 해소하지 않는다 — 억지로 닫으면 신학적 정직성을 잃는다.
