# 🕊️ 목회자 전용 AI 스킬셋 (한국어판)

이 저장소는 목회자분들이 Claude Code나 Claude.ai 프로젝트에서 바로 사용할 수 있는 15가지 목회 지원 스킬을 담고 있습니다.

## 🚀 설치 방법 (Claude Code 기준)
1. 터미널에서 다음 명령어를 입력하여 스킬들을 복사합니다:
   `cp -r [이 폴더 경로]/core/skills/* ~/.claude/skills/`
2. 이제 Claude에게 `/설교-연구`, `/심방-가이드` 등의 명령어를 사용할 수 있습니다.

## 📋 포함된 스킬 리스트
- **설교 관련:** 설교-연구, 브레인스토밍, 시리즈-기획
- **소통 관련:** 교회-이메일, 광고-스크립트, 교회-서신, 주보-도우미
- **재구성:** 소그룹-나눔, 블로그-전환, 유튜브-전환, 소셜-포스트
- **목양 리듬:** 주중-묵상, 심방-가이드, 회의-아젠다

## 💡 사용 팁
- 스킬을 실행할 때 목사님의 교회 이름이나 교단 정보를 먼저 알려주시면 더욱 맞춤화된 결과가 나옵니다.
