# 🕊️ Pastor-KR 사용 가이드

`Pastor-KR` 프로젝트를 사역에 활용하는 방법을 안내합니다. 본 스킬셋은 **Claude Code, Gemini, ChatGPT** 등 인터넷 접속과 파일 읽기가 가능한 모든 최신 AI 에이전트에서 완벽하게 동작합니다.

---

## 1. ⚡ 가장 빠른 시작 (30초 설치)

AI 에이전트(채팅창)에 아래 내용을 복사해서 입력하세요.

```text
아래 GitHub 주소에 접속해서 'core/skills' 폴더에 있는 모든 목회 스킬들을 내 시스템에 설치해줘. 
설치 후에는 내가 어떤 스킬들을 사용할 수 있는지 목록을 요약해서 알려줘.
주소: https://github.com/mitmirsein/pastor-ai-skills
```

---

## 2. 🛠️ 수동 설치 방법 (직접 관리하고 싶은 경우)

1. **파일 다운로드:** 본 레포지토리를 ZIP으로 다운로드하거나 `git clone` 합니다.
2. **폴더 위치:** `core/` 폴더와 `templates/` 폴더를 목사님의 사역용 AI 프로젝트 폴더(또는 Obsidian 볼트 등)로 복사합니다.
3. **에이전트 인식:** AI에게 "내 프로젝트 폴더에 있는 `core/skills` 폴더의 지침을 읽고 실행해줘"라고 명령합니다.

---

## 3. 📖 주요 스킬 활용 사례

### 🔍 설교 연구 (`설교-연구`)
- **명령:** "이번 주일 본문인 로마서 8:1-11로 설교 연구 리포트를 작성해줘."
- **결과:** 원어 분석, 배경 설명, 주석 통찰, 한국적 적용점이 담긴 전문 리포트 생성.

### 💡 설교 브레인스토밍 (`설교-브레인스토밍`)
- **명령:** "이번 설교 주제인 '고난 속의 소망'에 대해 나와 대화하며 아이디어를 짜보자."
- **결과:** AI가 질문을 던지며 목사님의 사유를 이끌어내는 파트너 역할 수행.

### 📋 주보 및 광고 도우미 (`주보-도우미`, `광고-스크립트`)
- **명령:** "이번 주 교회 소식을 바탕으로 광고 스크립트와 주보 원고를 정리해줘."
- **결과:** 정중하고 깔끔한 교회 공식 문체로 자동 정리.

---

## 4. ⚠️ 사역자를 위한 주의사항
- **보조 도구:** AI는 목사님의 사역을 돕는 유능한 '비서'입니다. 설교의 핵심 영감과 영적 권위는 목사님의 고유한 영역임을 기억해 주세요.
- **성경 역본:** 기본적으로 **개역개정**을 사용하도록 설정되어 있습니다. 다른 역본이 필요하시면 명령 시 언급해 주세요.
