# Pastor-KR

목회자의 매일 묵상을 설교·주보 칼럼·성도 묵상으로 이어 주는 한국어 AI 목회 비서 스킬셋입니다.

자연어로 요청하면 `Pastor-Concierge`가 진행 중인 사역과 교회력 맥락을 읽고, 필요한 전문 스킬을 같은 대화에서 실행합니다. AI는 연구·구조·목양·재생산을 돕고, 설교의 핵심 사유와 집필·최종 판단은 목회자에게 남깁니다.

![큐티에서 설교와 칼럼으로 이어지는 Pastor-KR 파이프라인](assets/qt-sermon-column-pipeline.jpg)

## 시작하기

이 안내서는 `core/`·`skills/`의 전문 지침과 함께 사용합니다. 파일을 읽고 쓸 수 있는 도구에서는 이 저장소 폴더를 연 뒤 다음처럼 요청하세요.

```text
USER_GUIDE.md와 skills/00_pastor_concierge/SKILL.md를 읽고
Pastor-Concierge로 시작해 줘. 내 요청에 필요한 전문 지침을 로드해
이 대화에서 바로 실행해 줘. 충분한 정보가 있으면 다시 묻지 말고,
저장할 수 없는 환경이면 그 사실과 복사할 저장 블록을 알려 줘.
```

처음부터 전체 설정을 끝낼 필요는 없습니다. 다음 세 문장 중 하나를 바로 보내 첫 결과를 받아 보세요.

```text
오늘 큐티 본문과 내 묵상을 붙여넣을 테니, 질문 없이 원문을 기록해 줘.
```

```text
이번 주일 본문은 [본문]이야. 이미 준 본문으로 설교 준비를 시작해 줘.
```

```text
이 큐티로 성도들과 나눌 600자 주보 칼럼을 만들어 줘.
```

일반 웹 채팅에서는 필요한 스킬 지침과 본문·원고를 이 대화에 직접 제공하세요. 웹 채팅이 저장할 수 없는데도 자동 저장되었다고 말하지 않으며, 결과 뒤에 복사해 보관할 위치와 블록을 안내합니다. 파일 접근 환경에서는 전문 지침을 읽고 결과를 같은 대화에서 만들며, 쓰기 권한이 있을 때 공통 훅에 따라 저장하고 실제 저장 결과를 보고합니다.

## 이렇게 요청하세요

| 하고 싶은 일 | 요청 예시 |
|---|---|
| 매일 묵상 | “오늘 큐티를 함께 깊이 읽어 줘.” |
| 설교 준비·점검 | “이 본문을 연구해 줘.” · “내 개요의 구조만 봐 줘.” |
| 목양 | “내일 심방에서 전할 위로 말씀과 대화 가이드를 준비해 줘.” |
| 주보 칼럼·성도 묵상 | “이 큐티로 성도들과 나눌 글을 만들어 줘.” |
| 회고·조회 | “지난 설교를 돌아보고 이번 주 준비를 정리해 줘.” |

묵상 원문을 보존하고 반복되는 본문·주제·남은 질문을 씨앗으로 모읍니다. 씨앗은 설교 준비나 칼럼·성도 묵상으로 이어지고, 회고는 다음 준비에 반영됩니다. 일반 공문, 회의 안건, 행사 광고, 대외 이메일, 전용 목회 서신은 이 프로젝트의 지원 범위에 포함하지 않습니다. 주보 칼럼과 개별 심방 동행은 계속 지원합니다.

## 사용 원칙

- **본문 먼저:** 확보한 본문과 출처를 대조합니다. 기억으로 성경을 인용하거나 없는 원어 근거를 만들지 않습니다.
- **목회자 중심:** 초기 묵상과 문체를 존중하며 설교를 대필하지 않습니다.
- **같은 대화에서 실행:** 파일 환경에서는 Concierge가 선택한 전문 스킬 지침을 읽고 바로 실행합니다. 이미 준 본문·원고·대상·분량은 다시 묻지 않습니다.
- **사역 연속성:** 쓰기 가능한 환경에서는 결과를 `outputs/`에, 진행 상태를 목회 메모리에 기록합니다. 설교 자료는 본문별로 모입니다.
- **돌봄과 개인정보:** 위기 상황에서는 전문 연계가 우선입니다. 메모리에 성도 실명·연락처·상세 병명을 기록하지 않습니다.
- **발행 전 점검:** 설교·칼럼·성도 묵상은 필요할 때 [품질 감사](harness/sermon_audit.md)로 근거와 표현을 확인합니다.
