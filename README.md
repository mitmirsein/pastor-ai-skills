# Pastor-KR

목회자의 매일 묵상을 설교·칼럼·성도 묵상으로 이어 주는 한국어 AI 목회 비서 스킬셋입니다.

자연어로 요청하면 **Pastor-Concierge**가 진행 중인 사역과 교회력 맥락을 읽고 알맞은 스킬로 안내합니다. AI는 연구·구조·행정을 돕고, 설교의 핵심 사유와 집필·최종 판단은 목회자에게 남깁니다.

![큐티에서 설교와 칼럼으로 이어지는 Pastor-KR 파이프라인](assets/qt-sermon-column-pipeline.jpg)

## 시작하기

저장소를 내려받아 AI 작업 도구에서 폴더를 열고 다음과 같이 요청하세요.

```text
USER_GUIDE.md와 skills/00_pastor_concierge/SKILL.md를 읽고
Pastor-Concierge로 시작해 줘. 처음 설정이 필요하면 안내해 줘.
```

파일 접근이 없는 챗 환경에서는 필요한 지침과 본문을 직접 제공하세요. 결과는 자동 저장 대신 복사용 블록으로 받습니다. 자세한 설정은 [사용 가이드](USER_GUIDE.md)를 참고하세요.

## 이렇게 요청하세요

| 하고 싶은 일 | 요청 예시 |
|---|---|
| 매일 묵상 | “오늘 큐티를 함께 깊이 읽어 줘.” |
| 설교 준비 | “최근 큐티에서 설교로 발전할 만한 씨앗을 찾아 줘.” |
| 본문 연구 | “이 본문의 원어와 문맥을 주해해 줘.” |
| 칼럼·성도 묵상 | “이 큐티로 성도들과 나눌 묵상을 만들어 줘.” |
| 목양·행정 | “이번 구역 모임 나눔 질문을 준비해 줘.” |
| 회고·조회 | “지난 설교를 돌아보고 이번 주 준비를 정리해 줘.” |

큐티 원문을 보존하고 반복되는 본문·주제·남은 질문을 씨앗으로 모읍니다. 씨앗은 설교 준비나 칼럼·성도 묵상으로 이어지고, 회고는 다음 준비에 반영됩니다.

## 사용 원칙

- **본문 먼저:** 확보한 본문과 출처를 대조합니다. 기억으로 성경을 인용하거나 없는 원어 근거를 만들지 않습니다.
- **목회자 중심:** 초기 묵상과 문체를 존중하며 설교를 대필하지 않습니다.
- **사역 연속성:** 파일 접근 환경에서는 결과를 `outputs/`에, 진행 상태를 목회 메모리에 기록합니다. 설교 자료는 본문별로 모입니다.
- **돌봄과 개인정보:** 위기 상황에서는 전문 연계가 우선입니다. 메모리에 성도 실명·연락처·상세 병명을 기록하지 않습니다.
- **발행 전 점검:** 설교·칼럼·성도 묵상은 [품질 감사](harness/sermon_audit.md)로 근거와 표현을 확인하세요.
