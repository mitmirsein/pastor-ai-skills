# 🕊️ Pastor-KR (목회자 AI 스킬셋 한국어판)

본 레포지토리는 Thomas Costello의 [pastor-ai-skills](https://github.com/tkcostello/pastor-ai-skills)를 기반으로 하여, 한국 목회 환경에 맞게 리폼(Reform)하고 현지화한 버전입니다.

## 🚀 프로젝트 소개
`Pastor-KR`은 목회자분들이 Claude Code나 Claude.ai 프로젝트에서 바로 사용할 수 있는 15가지 목회 지원 스킬을 담고 있습니다. 미국식 실용주의 워크플로우를 한국 교회의 정서와 신학적 맥락(개역개정 성경, 교구/구역 문화 등)에 맞게 재구축하였습니다.

## 📋 포함된 스킬 리스트
- **설교 관련:** 설교-연구, 브레인스토밍, 시리즈-기획
- **소통 관련:** 교회-이메일, 광고-스크립트, 교회-서신, 주보-도우미
- **재구성:** 소그룹-나눔, 블로그-전환, 유튜브-전환, 소셜-포스트
- **목양 리듬:** 주중-묵상, 심방-가이드, 회의-아젠다
