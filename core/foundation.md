# ⚓ Pastor-KR Foundation

본 파일은 `Pastor-KR` 프로젝트의 **단일 진실 공급원(SSOT)**입니다. 모든 목회 지원 스킬은 위 메타데이터를 참조하여 결과물을 개인화합니다.

## 설정 가이드
1. 위 YAML 프론트매터의 내용을 지인 목회자의 상황에 맞게 수정하세요.
2. 각 스킬 실행 시 이 설정을 기반으로 '우리 교회 맞춤형' 톤앤매너가 적용됩니다.
3. 신학 용어의 경우 `MS_Dev`의 TRE 용어집과 연동되어 정확한 표현을 유지합니다.
