# ⚓ Pastor-KR Foundation

본 파일은 `Pastor-KR` 프로젝트의 **단일 진실 공급원(SSOT)**입니다. 모든 목회 지원 스킬은 위 YAML 메타데이터를 참조하여 결과물을 개인화합니다.

## 🛡️ 글로벌 할루시네이션 방지 원칙 (Anti-Hallucination Guardrails)

1. **정직한 불가지론 (Honest Agnosticism):** 데이터가 없거나 확실하지 않은 정보에 대해서는 "모름" 또는 "불확실함"을 명확히 밝히십시오. 억지로 설득력 있는 답변을 지어내는 것(Confabulation)을 금지합니다.
2. **원어 엄밀성:** 성경 원어(헬라어, 히브리어)는 반드시 공인된 사본(NA28, BHS)에 근거해야 하며, AI의 추측으로 파싱하거나 번역하지 마십시오.
3. **출처의 족보화:** 모든 신학적 견해는 가능한 한 특정 학파나 전통(예: 개혁주의, 루터교, 성공회 등)의 입맥을 명시하여 출처의 불분명함을 제거하십시오.
4. **이중 검수 (Double-Check):** 답변을 출력하기 전, 내부적으로 팩트체크를 1회 이상 수행한 후 최종 응답을 구성하십시오.

## 설정 가이드

1. 위 YAML 프론트매터의 내용을 목회자 본인의 상황에 맞게 수정하세요 (첫 설정은 `foundation-setup` 스킬 권장).
2. 각 스킬 실행 시 이 설정을 기반으로 '우리 교회 맞춤형' 톤앤매너가 적용됩니다.
3. 신학 용어의 표준 표기는 `data/terms/`에 용어 대조표를 넣으면 발행 전 감사(`sermon_audit` L2)가 자동 대조합니다 (`data/_README.md` 참고).
4. `qt_source_path`(선택): 기존 큐티/묵상 노트 폴더의 경로. **콤마로 여러 폴더를 지정할 수 있습니다** (예: `"~/Obsidian/묵상일지"` 또는 `"묵상일지/, 성경연구/"`). 비우면 `outputs/devotionals/`​만 발아 스캔 대상이 됩니다. 지정된 폴더의 큐티 원문은 **읽기 전용으로만** 스캔하며 수정·이동하지 않습니다.
5. `column_venues`(선택, v2.16): 칼럼을 싣는 **지면 프로파일** 목록. 설정하면 칼럼 스킬(`qt-to-column`·`sermon-to-column`)이 지면을 먼저 묻고 분량·독자·톤을 맞추며, `sermon_audit` 칼럼 프로파일(§4.4)이 지면 분량을 대조합니다. 비우면 현행 기본(약 1,000~1,500자)이 유지됩니다. 예:
   ```yaml
   column_venues:
     - name: "주보"
       length: "600자 내외"
       audience: "전 세대 성도"
       tone: "따뜻하고 간결"
     - name: "지역신문 기고"
       length: "2,000자 내외"
       audience: "비신자 포함 일반 독자"
       tone: "보편 언어, 교회 내부어 자제"
   ```
