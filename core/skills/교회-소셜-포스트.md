# 📱 교회-소셜-포스트 (Church Social Post KR)

성도들이 일상 속에서 가볍게 읽고 공유할 수 있는 소셜 미디어용 콘텐츠를 만듭니다.

## 📝 플랫폼별 전략
- **인스타그램:** 감성적인 인용구 중심, 해시태그 활용.
- **페이스북:** 조금 더 긴 호흡의 나눔과 교회 소식 중심.
- **카카오톡 채널:** 공지사항과 핵심 메시지 요약 중심.
