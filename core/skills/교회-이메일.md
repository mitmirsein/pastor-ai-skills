# 📧 교회-이메일 (Church Email KR)

본 스킬은 목회자의 따뜻한 마음이 담긴 주간 소식지나 안내 이메일을 전문적이고 친근하게 작성합니다.

## 📝 작성 원칙
1. **친절한 톤앤매너:** 너무 딱딱하지 않으면서도 목회적 권위가 느껴지는 문체를 사용합니다.
2. **명확한 정보 전달:** 중요한 공지사항이나 예배 안내가 한눈에 들어오게 배치합니다.
3. **영적 권면 포함:** 단순 공지를 넘어 한 주간을 살아갈 성도들을 위한 짧은 격려 메시지를 포함합니다.

## 📄 출력 구성
- **제목:** 클릭하고 싶게 만드는 매력적인 제목.
- **미리보기(Preview):** 이메일 목록에서 보여질 짧은 요약 문구.
- **본문:** 인삿말 - 주요 소식 - 영적 권면 - 맺음말 순으로 구성.
