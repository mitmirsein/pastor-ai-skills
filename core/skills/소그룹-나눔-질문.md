# 🗣️ 소그룹-나눔-질문 (Small Group Questions KR)

본 스킬은 주일 설교의 메시지가 성도들의 삶에서 구체적인 나눔으로 이어지도록 돕는 질문지를 만듭니다.

## 🛠️ 질문 구성 원칙
1. **아이스브레이커:** 가볍게 마음을 열 수 있는 일상적인 질문 (1개).
2. **관찰(Observation):** 설교 본문의 핵심 내용을 다시 확인하는 질문 (1~2개).
3. **해석(Interpretation):** 본문의 의미가 오늘날 우리에게 어떤 메시지를 주는지 생각하게 하는 질문 (1~2개).
4. **적용(Application):** 한 주간의 삶에서 구체적으로 실천할 '행동'을 이끌어내는 질문 (2~3개).

## 📄 출력 지침
- 소그룹 인도자가 바로 사용할 수 있도록 깔끔한 인쇄용 레이아웃으로 출력합니다.
- 설교의 핵심 요약(3~4문장)을 상단에 포함합니다.
