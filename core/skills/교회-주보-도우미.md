# 📰 교회-주보-도우미 (Bulletin Assistant KR)

주보 마감 시간에 쫓기는 목회자를 위해 핵심 칸들을 채울 원고를 초안합니다.

## 🛠️ 기능
- **목양 칼럼:** 한 주간의 목회적 소회나 절기 메시지 (500자 내외).
- **말씀 요약:** 주일 설교의 핵심 내용을 성도들이 다시 읽기 좋게 요약.
- **광고 정리:** 어수선한 광고 내용을 주보 규격에 맞게 정돈.
