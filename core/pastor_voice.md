# 🎙️ 목회자 보이스 카드 (Pastor Voice) — v2.9 P1-4

<!-- Concierge 요약 헤더 (부트 시 이 블록만 로드) -->
> **요약**: 성도에게 도달하는 발행물(칼럼·블로그·TTS·카드뉴스·성도 묵상)은 **목회자 자신의 문체**로 쓰여야 한다. 문체 적용 순서는 **이번 요청의 명시 지시 → 해당 장르의 `confirmed` 변주 → `confirmed` 기본 카드 → 제공 원문의 임시 관찰/`foundation.md` 기본 톤**이다. `unset`·`draft` 카드는 확정 보이스로 적용하지 않는다. 외부 문체 모사는 이번 요청에서 명시한 경우에만 적용한다. 설정은 `voice-setup` 스킬로.
<!-- /요약 헤더 -->

```yaml
status: unset            # unset | draft | confirmed — confirmed만 적용 (목회자 확정 필수)
source_samples: 0        # 추출에 사용한 설교문/칼럼 편수
confirmed_on: null
```

> 🚨 **원칙**: 이 카드는 AI가 추정으로 채우지 않는다. `voice-setup` 인터뷰에서 **목회자의 실제 글 샘플 인용에 정착**시켜 초안을 만들고, **목회자가 교정·확정**해야 `confirmed`가 된다. 보이스 카드는 편의 기능이 아니라 **대필 방지 안전장치**다 — AI가 남의 문체를 입히는 것을 막고 목회자 자신의 문체를 보존·증폭한다.

---

## 보이스 카드 (voice-setup이 채움)

### 1. 문장 호흡 (Cadence)
- 평균 문장 길이: (미설정)
- 종결어미 분포: (예: ~습니다 70% / ~지요 15% / 명사형 종결 15%)
- 근거 샘플 인용: (없음)

### 2. 어휘 지문 (Lexicon)
- 자주 쓰는 표현(시그니처): (미설정)
- 피하는 표현(목회자 확정 항목만): (미설정)
- 회중 호명 방식: (예: "사랑하는 성도 여러분" / "여러분" / 무호명)

### 3. 예화 스타일 (Illustration)
- 선호 원천: (예: 일상 관찰 / 역사 / 문학 / 자연)
- 길이·빈도: (미설정)

### 4. 강조 패턴 (Emphasis)
- 반복·질문·침묵 등 강조 장치: (미설정)

### 5. 주의 신호 (Watch)
- 이 목회자답지 않은 문장 유형: (예: 논문체, 과장된 수사, 채점하는 어조)

### 6. 장르 변주 (Genre Variants) — 선택
같은 보이스라도 매체에 따라 옷이 다릅니다 — 강단의 호명·반복을 지면에 그대로 이식하면 어색해집니다. **해당 장르의 실제 샘플이 있을 때만** 채웁니다(추정 금지 — 샘플 없으면 "(샘플 부족)").
- **강단 (설교)**: (예: 회중 호명 빈번, 반복 강조, 긴 호흡 허용)
- **지면 (칼럼·블로그)**: (샘플 부족)
- **메신저 (성도 묵상·TTS)**: (샘플 부족)
- **카드뉴스**: (샘플 부족)

> 발행 스킬 적용 규칙: 이번 요청의 명시 지시가 있으면 그것을 우선한다. 그다음 카드가 `confirmed`이고 해당 장르 변주가 실제로 채워져 있으면 그 변주를 적용하고, 없으면 카드 본체(§1~5)를 적용한다. 카드가 `unset`·`draft`이면 제공 원문의 임시 관찰 또는 `foundation.md` 기본 톤으로 폴백한다.

> **규칙 기반 장르 변주 폴백 (v2.19):** 카드가 `confirmed`인데 해당 장르 변주가 "(샘플 부족)"이면, 칼럼·블로그는 강단 보이스에서 회중 호명·반복을 줄이고 문단을 나누는 **형식 변환**만 적용할 수 있습니다. 어휘·시그니처·금기 표현을 추정해 채우지 않으며, 산출물 제작 메모에 `(장르 변주는 추정 — 목회자 확인 필요)`를 표기합니다. 실제 장르 샘플이 2편 이상 쌓이면 `voice-setup`이 실측 변주로 교체를 제안합니다.
