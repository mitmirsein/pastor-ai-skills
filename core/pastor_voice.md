# 🎙️ 목회자 보이스 카드 (Pastor Voice) — v2.9 P1-4

<!-- Concierge 요약 헤더 (부트 시 이 블록만 로드) -->
> **요약**: 성도에게 도달하는 발행물(칼럼·블로그·TTS·카드뉴스·목회서신)은 **목회자 자신의 문체**로 쓰여야 한다. 본 카드가 설정되어 있으면(`status: confirmed`) 발행 스킬들은 외부 문체 모사(피터슨/켈러 풍)를 기본값에서 **옵션으로 강등**하고 이 카드를 기본값으로 삼는다. 미설정이면 `foundation.md`의 `tone_preference`로 폴백한다. 설정은 `voice-setup` 스킬로.
<!-- /요약 헤더 -->

```yaml
status: unset            # unset | draft | confirmed — confirmed만 적용 (목회자 확정 필수)
source_samples: 0        # 추출에 사용한 설교문/칼럼 편수
confirmed_on: null
```

> 🚨 **원칙**: 이 카드는 AI가 추정으로 채우지 않는다. `voice-setup` 인터뷰에서 **목회자의 실제 글 샘플 인용에 정착**시켜 초안을 만들고, **목회자가 교정·확정**해야 `confirmed`가 된다. 보이스 카드는 편의 기능이 아니라 **대필 방지 안전장치**다 — AI가 남의 문체를 입히는 것을 막고 목회자 자신의 문체를 보존·증폭한다.

## 보이스 카드 (voice-setup이 채움)

### 1. 문장 호흡 (Cadence)
- 평균 문장 길이: (미설정)
- 종결어미 분포: (예: ~습니다 70% / ~지요 15% / 명사형 종결 15%)
- 근거 샘플 인용: (없음)

### 2. 어휘 지문 (Lexicon)
- 자주 쓰는 표현(시그니처): (미설정)
- 피하는 표현(금기): (미설정)
- 회중 호명 방식: (예: "사랑하는 성도 여러분" / "여러분" / 무호명)

### 3. 예화 스타일 (Illustration)
- 선호 원천: (예: 일상 관찰 / 역사 / 문학 / 자연)
- 길이·빈도: (미설정)

### 4. 강조 패턴 (Emphasis)
- 반복·질문·침묵 등 강조 장치: (미설정)

### 5. 주의 신호 (Watch)
- 이 목회자답지 않은 문장 유형: (예: 논문체, 과장된 수사, 채점하는 어조)

### 6. 장르 변주 (Genre Variants) — 선택
같은 보이스라도 매체에 따라 옷이 다릅니다 — 강단의 호명·반복을 지면에 그대로 이식하면 어색해집니다. **해당 장르의 실제 샘플이 있을 때만** 채웁니다(추정 금지 — 샘플 없으면 "(샘플 부족)").
- **강단 (설교)**: (예: 회중 호명 빈번, 반복 강조, 긴 호흡 허용)
- **지면 (칼럼·블로그)**: (예: 호명 절제, 문단 짧게, 종결어미는 동일 유지)
- **메신저 (카톡 묵상)**: (미설정)

> 발행 스킬 적용 규칙: 카드가 confirmed이고 이 섹션에 해당 장르 변주가 있으면 **그 변주를 우선 적용**하고, 없으면 카드 본체(§1~5)를 적용합니다.

> **추정 변주 폴백 (v2.19):** 카드가 confirmed인데 '지면' 변주가 "(샘플 부족)"이면, 칼럼 스킬은 강단 보이스(§1~5)에서 **규칙 기반 파생**으로 지면 변주를 근사할 수 있습니다 — ① 회중 호명 제거 ② 문단 길이 설교 대비 절반 ③ 반복 강조 하향 ④ 구어투의 문어 전환(종결어미의 결은 유지). 이 파생은 카드의 실질(어휘·시그니처)을 지어내는 것이 아니라 **변환 규칙의 적용**이므로 추정 금지 원칙과 충돌하지 않습니다. 단 산출물 말미에 반드시 `(지면 변주는 추정 — 목회자 확인 필요)`를 표기하고, 목회자가 확인하면 그 규칙을 이 섹션에 기록합니다. 실제 칼럼 샘플이 2편 이상 쌓이면 `voice-setup`이 실측 변주로 교체를 제안합니다.
